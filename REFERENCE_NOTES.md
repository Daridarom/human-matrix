# Human Matrix — reference notes

Обновлено: 2026-09-15

## Что добавлено в рабочую базу

В приватной папке проекта `ДЧ` на Google Drive лежат три справочных PDF:

1. Линда Баннелл, Ра Уру Ху — «Дизайн Человека. Наука о Дифференциации».
2. «Рэйв Картография. Учебное пособие».
3. Петер Шёбер — «Основы системы Дизайн Человека. Центры».

PDF и пользовательские скриншоты в публичный репозиторий не копируются. Они используются только как референсы для терминологии, структуры чтения карты и визуального сравнения.

## Закреплённые продуктовые решения

- Бодиграф остаётся главным объектом экрана, без декоративной «витиеватости» каналов.
- Два слоя должны читаться сразу: Дизайн / бессознательное — красный; Личность / сознательное — чёрный.
- Планетарные активации `ворота.линия` должны быть видны рядом с картой и не исчезать на мобильном экране.
- На широком экране колонки активаций стоят по сторонам бодиграфа; на узком переходят под карту двумя читаемыми колонками.
- Ключевые параметры карты — тип, авторитет, профиль и определённость — показываются рядом с картой без необходимости искать их ниже по странице.
- В расшифровке приоритет первого слоя: Стратегия и Внутренний Авторитет. Профиль, центры, каналы, ворота и интегральные интерпретации раскрываются дальше.
- Рассчитанные данные, традиционная трактовка Human Design и интегральные/психологические гипотезы должны быть различимы по смыслу и не смешиваться в утверждения «как факт».

## Что пока не добавляем

На визуальных референсах есть четыре стрелки R/L, цвет, тон, база и дополнительные маркеры. Эти значения не выводятся до тех пор, пока для них не будет отдельного проверенного расчёта и набора контрольных карт. Визуальное сходство не должно достигаться за счёт приблизительных или выдуманных значений.

## Следующий контроль качества

1. Проверить v0.8 на iPhone шириной 390–430 px: карта, обе колонки и значения `ворота.линия` должны оставаться читаемыми.
2. Сверить не менее трёх контрольных карт с внешними источниками по планетарным активациям, профилю, типу, авторитету и определённым центрам.
3. После этого отдельно проектировать слой переменных R/L, цвет / тон / база.
