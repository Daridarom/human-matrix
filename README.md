# Human Matrix

Экспериментальный веб-интерфейс для исследования человека, пары и малой команды через Human Design и подключаемые символико-календарные системы.

**Live:** https://daridarom.github.io/human-matrix/

## Что работает сейчас

- до 5 локальных профилей;
- дата, время, место и IANA-часовой пояс рождения;
- локальный расчёт Personality/Design planetary activations через `hd-chart-engine`;
- активированные ворота и 36 каналов;
- определённые/открытые центры;
- Type, Strategy, Authority, Profile;
- собственная функциональная визуализация центров;
- базовый connection layer для пары;
- агрегированная матрица команды без выдачи её за BG5/Penta;
- практические гипотезы, отделённые от вычисленных данных;
- журнал наблюдений;
- экспорт/импорт профилей JSON.

## Архитектурный принцип

`расчёт → трактовка → гипотеза → наблюдение`

Эти уровни не смешиваются. Символический вывод не становится фактом только потому, что он показан рядом с расчётом.
