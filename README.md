# Human Matrix

[Открыть приложение](https://daridarom.github.io/human-matrix/)

Версия 0.5: личная карта Human Design, расшифровка, совместимость, транзиты и наблюдения.

## Реализовано

- Девять геометрических центров, 64 ворот и 36 каналов в собственном SVG. Нажатие на центр или ворота открывает пояснение.
- Чёрный / красный слои личности и дизайна, отображение половин каналов и совмещённых активаций.
- Тип, профиль, авторитет, стратегия, группы определённости, описания 9 центров, 64 ворот и 36 каналов.
- Карта пары с цветами участников, конфигурацией определённых центров и четырьмя видами связей. Указан вклад каждого участника.
- Транзиты на дату и местное время: самостоятельная карта момента либо наложение на личную карту. Дизайн до рождения не включается в транзит.
- До пяти профилей, редактирование, локальные заметки и JSON-экспорт/импорт с сохранением совместимости v1.
- Валидация даты 1800–2200, IANA-зоны, отсутствующего или повторяющегося времени при переводе часов. При неизвестном времени личная карта не назначается.

## Расчёт и трактовка

Используется MIT-путь `hd-chart-engine` / Astronomy Engine. Тексты — оригинальные краткие пояснения в рамках символической системы, не научная психодиагностика или прогноз отношений. Проценты совместимости не рассчитываются. Тоны, базы, стрелки, диетические предписания и медицинские характеристики не интерпретируются.

## Запуск

`npm ci` → `npm run build` → `npm test`.

Статические файлы в корне обслуживаются GitHub Pages. Для локального просмотра: `python -m http.server 4180`.

## Проверка

- Два исходных теста движка.
- 26 независимых пар «ворота / линия» из предоставленной контрольной карты.
- Карта пары: 7–2 центров; 5 электромагнитных, 2 компромиссных, 7 доминирующих, 0 общих каналов.
- Границы дат, эквивалентность исторического времени UTC, пропуски и повторы времени DST.
- Состав транзита из 13 текущих активаций, смена даты, покрытие схемы и текстов.
- DOM-проверка основных пользовательских сценариев с jsdom. Реальная браузерная проверка опубликованной версии выполняется отдельно.

Это ограниченная регрессия, а не гарантия совпадения всех возможных дат с любым внешним сервисом.

Профили и заметки остаются в localStorage браузера. Серверная синхронизация отсутствует. Загруженные пользователем образцы и сведения о втором человеке не публикуются в приложении.
