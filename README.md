# Human Matrix

Экспериментальный веб-интерфейс для исследования Human Design, BG5 и дополнительных календарно-символических систем.

## Направления
- профиль одного человека;
- анализ взаимодействия пары;
- анализ малой команды 3–5 человек;
- Human Design и BG5;
- подключаемые майянские, славянские и астрологические слои;
- отдельный слой фактических наблюдений.

## Принцип
Расчёт → трактовка → гипотеза → наблюдение. Эти уровни не смешиваются.

Текущая версия — интерфейсный прототип. Реальный расчёт BodyGraph будет подключён отдельным вычислительным модулем после верификации на эталонных картах.
